# GameShell assembly study — sources

The user-provided reference depicts ClockworkPi GameShell hardware.

Original button meshes: https://github.com/clockworkpi/3Dmodel/blob/master/STL/GameShell_keys_only_buttons.stl (GPL-3.0). Full source STL and LICENSE accompany the five extracted binary meshes. Extraction removes the print sprue, centres each component, and scales metres into scene units. The source and extraction scripts are retained in the workspace.

Shell and modular enclosures: independently reconstructed geometry based on the supplied image. They are not manufacturer CAD. The publicly listed front/rear files at https://www.thingiverse.com/thing:2661013 were identified but not imported because automated retrieval was blocked.

Three.js: MIT, see ../vendor/THREE-LICENSE.txt.

This is a visual reconstruction, not manufacturing geometry. Hidden circuitry and surfaces not visible in the reference are illustrative.
